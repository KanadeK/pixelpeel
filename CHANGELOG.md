# Changelog

All notable changes to PixelPeel are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-07-16

### Added

- Local PNG, JPEG, and WebP import by picker, drag and drop, and clipboard paste, including browser decoding and a 40-megapixel guard.
- Transparent-canvas normalization for different image dimensions with center and top-left alignment.
- Peel, Overlay, Blink, and Diff comparison modes.
- Real pixel-difference metrics and adjustable sensitivity.
- Fit, 100%, zoom, pan, and light, dark, or checkerboard preview backgrounds.
- Full-resolution diff PNG, PR report PNG, and Markdown PR summary exports.
- Bundled example images, English and Simplified Chinese UI, theme switching, keyboard shortcuts, responsive layout, and accessibility support.
- Unit and Playwright end-to-end test coverage.
- GitHub Actions quality checks and GitHub Pages deployment workflow.
